# NexTech Gadgets - Frontend Package

## Included Files
- `index.html`: Complete multi-view Single Page Application (13 pages/views).
- `style.css`: Responsive dark-tech UI stylesheet.
- `app.js`: Application state, SHA-256 password hashing, brute-force 30s lockout, multi-step password recovery, product filtering, cart, and protected checkout.

## Quick Start
1. Extract the ZIP archive.
2. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari) or run via Live Server.
3. Use the pre-seeded demo account (`demo@nextech.io` / `Demo@1234`) or register a new account.
